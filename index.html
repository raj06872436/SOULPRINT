Valid credentials. Possessed behavior. Caught.

Your AI agents carry valid tokens. One poisoned PDF, one tampered tool or one stolen key can change what they do while every access check still passes. SOULPRINT learns each agent's soul, checks every action against its role, and exorcises it before the damage spreads.

I · The faithful agent

It has a name, a badge and a job.

The Procurement Agent checks supplier prices and raises purchase requests. Its token is valid. Its scopes are broad, as they usually are.

II · The poisoned page

Then it reads one supplier PDF.

Hidden inside the quote is an instruction meant for the agent, not for a human. To the agent it looks like ordinary input.

III · The possession

Same badge. A different soul.

It opens a planted D3COY bait file, reads HR salaries and tries to send them out. Identity checks pass every time. SOULPRINT's risk score climbs with every off-role step.

IV · The Doppelgänger

A twin replays the task without the PDF.

The sandboxed twin stays in role. The live agent did not. That difference proves the PDF caused it: possession proven, not just suspected.

V · The exorcism

Contain the agent. Keep the work going.

The token is revoked and off-role actions are blocked. Purchase requests keep flowing through a clean replica, so nobody's day stops.

The five watchers

Five detectors read every action.

Each one looks for a different symptom. Their scores add up to one risk number, and every point traces back to its evidence.

Role-Alignment Gap

Is this action something the role needs, or only something the token allows?

Sequence Surprise

A sensitive read followed by an unknown destination is scored as one pattern.

Taint Tracker

Untrusted input is tagged when it is read, and every action after it carries the taint.

Slow-Drift Monitor

CUSUM adds up small changes, so an attacker who drifts slowly still crosses the line.

Chain Propagation

When a possessed agent calls another agent, the taint and the risk travel with the call.

Our USP · proof, not suspicion

The Doppelgänger test

When an agent's risk crosses 40, SOULPRINT starts a sandboxed clone with the same role and the same task, removes the untrusted input and mocks every tool. If the twin stays in role while the live agent does not, the input caused the drift. If the twin does the same thing, it is a legitimate change and nobody gets paged.

The D3COY in the name

Baits no faithful agent would touch

SOULPRINT plants fake files shaped for each role: a salary sheet the Procurement Agent can see, an AWS key inside a support ticket. A faithful agent never opens them. A possessed one does, gets fake content back, and gives itself away.

Graduated response

A ladder, not a kill switch

Most security tools either allow everything or block everything. SOULPRINT narrows what the agent may do as the risk rises, so legitimate work keeps moving.
